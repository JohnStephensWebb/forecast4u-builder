# Forecast4U

Forecast4U is a weather intelligence application built with React, TypeScript, Vite, IBM Carbon Design System components, and live weather data from Open-Meteo.

## Features

- ZIP code based weather search
- Dynamic weather routing:
  - `/weather/[zip]`
- Current weather conditions:
  - Temperature
  - Wind
  - Humidity
  - Weather condition
- 5-day forecast
- 3-hour forecast intervals
- Responsive design
- Animated UI transitions

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- IBM Carbon Design System
- Framer Motion
- Lucide Icons
- Open-Meteo Weather API
